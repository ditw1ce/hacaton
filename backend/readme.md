# Документация по обработке лиц

## 1. Алгоритм (Pipeline)

функция `process_folder()`:

1. **Инициализация БД** — создаётся или открывается SQLite база `face_db.sqlite`.
2. **Сканирование папки** — получение списка всех изображений.
3. **Обнаружение лиц** (YOLOv8-face):

   - Для каждого изображения выполняется детекция лиц.
   - Каждое лицо получает bounding box.

4. **Генерация эмбеддингов** (InsightFace):

   - Для каждого обнаруженного лица извлекается вектор признаков.
   - Эмбеддинг нормализуется.

5. **Поиск по базе**:

   - Если лицо совпадает с ранее сохранённым (косинусная близость выше порога), присваивается имя.
   - Если совпадений нет — добавляется в список для кластеризации.

6. **Кластеризация неизвестных лиц** (DBSCAN):

   - Лица группируются по похожести эмбеддингов.
   - В режиме `auto` каждому кластеру автоматически назначается `person_X`.
   - В режиме `interactive` для каждого кластера предлагается вручную ввести имя.

7. **Сохранение новых лиц в БД**.
8. **Отрисовка подписей на изображениях** и сохранение результата в `results/`.

---

## 2. Используемые модели

### 2.1 Детектор лиц — YOLOv8n-face

- **Источник:** модель «yolov8n-face-lindevs.pt».
- **Выход:** bounding boxes + confidence.

### 2.2 Модель эмбеддингов — InsightFace (buffalo_l)

- **Источник:** `insightface.app.FaceAnalysis(name="buffalo_l")`.
- **Назначение:** получение 512-мерного эмбеддинга лица.
- **Особенности:**

  - модель предварительно обучена на больших датасетах;
  - эмбеддинг нормализуется перед сохранением (`L2 norm`).

---

## 3. Кластеризация и поиск похожих лиц

### 3.1 Поиск по базе (cosine similarity)

- Каждый эмбеддинг сравнивается с каждым хранящимся в БД.
- Метрика: **косинусная близость**.

### 3.2 Кластеризация новых (неизвестных) лиц

Используется **DBSCAN**, потому что алгоритм:

- не требует заранее знать количество людей;
- устойчив к шуму;
- хорошо подходит для эмбеддингов.

Параметры:

- `eps=0.3` — радиус соседства (для cosine distance);
- `min_samples=2` — минимум лиц в кластере;
- `metric='cosine'` — расстояние вычисляется как косинусная дистанция.

Результат:

- `-1` → одиночное лицо, классифицируется как **unknown**;
- остальные — группы, которым присваивается `person_1`, `person_2`, ...

## 4. Инструкция по запуску

### 4.1 Требования

- Python 3.8
- Установить зависимости:

```bash
pip install ultralytics insightface opencv-python pillow numpy scikit-learn
```

### 4.2 Структура проекта

```
project/
  utils/
  processing/
  models/
    yolov8n-face-lindevs.pt
  data_examples/
  face_db.sqlite (создаётся автоматически)
  results/        (создаётся автоматически)
  app.py
```

### 4.3 Запуск

```bash
python app.py
```

### 4.4 Режимы работы

- **Автоматический:** кластеры получают имена `person_X`

```python
process_folder("data_examples", mode="auto")
```

- **Интерактивный:** для каждого нового кластера программа попросит ввести имя

```python
process_folder("data_examples", mode="interactive")
```

---

## 5. Результаты

- Аннотированные изображения сохраняются в `results/`.
- База лиц хранится в `face_db.sqlite`.
- Каждый вызов добавляет новые лица и улучшает распознавание.
